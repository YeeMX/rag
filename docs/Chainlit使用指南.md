# Chainlit 使用指南（劳动法 RAG 系统）

> 当前已有一个实例在运行：**http://127.0.0.1:8000**（离线 Mock 模式，无需 API Key）。
> 本文回答三个问题：**怎么打开、输入什么、会看到什么**。

---

## 1. 怎么打开

1. 浏览器打开 http://127.0.0.1:8000
2. 页面加载后会自动出现一条欢迎消息（知识库规模、检索链路、示例问题）
3. 在底部输入框输入问题 → 按 **Enter**（或点发送按钮）→ 等待 2~4 秒 → 得到回答

> 如果页面打不开（服务可能已停止），在 `01-labor-law-rag/` 目录下重新启动：

```powershell
cd "D:\Vibe Coding Projects\01-labor-law-rag"
$env:HF_HUB_DISABLE_XET = "1"      # 本机必须关 XET，否则模型下载会卡死
& "D:\Vibe Coding Projects\.venv-rag\Scripts\chainlit.exe" run app\chainlit_app.py --host 127.0.0.1 --port 8000
```

## 2. 输入什么才会有输出

**直接输入一句自然语言的劳动法问题即可**，不需要任何特殊命令或格式。推荐用下面 8 个问题（都经过实测，能稳定触发多路召回、重排、过滤、引用）：

| # | 复制这行输入 | 预期能看到什么 |
|---|---|---|
| 1 | `公司违法辞退我，月薪12000、工作3年7个月，能赔多少？` | 命中《劳动合同法》第87条 + 第47条，赔偿金 2N |
| 2 | `入职8个月没签劳动合同，被辞退能同时要双倍工资和赔偿金吗？` | 多意图分解成 2 个子查询，命中第82条 + 第87条 |
| 3 | `公司一直不给我缴社保，我可以要求补缴吗？` | 命中《社会保险法》第63条、第86条 |
| 4 | `试用期6个月但只签了1年合同，合法吗？` | 命中《劳动合同法》第19条、第83条 |
| 5 | `我怀孕5个月，公司说要裁员，可以解除我的劳动合同吗？` | 命中第42条（孕期不得解除）、第45条 |
| 6 | `平时加班、周末加班、国庆加班，加班费分别按几倍算？` | 命中《劳动法》第44条，1.5/2/3 倍分档 |
| 7 | `公司拖欠我两个月工资，我可以直接走人并要求经济补偿吗？` | 命中第38条（被迫解除）+ 第46条 |
| 8 | `竞业限制补偿金一直没给，我还需要遵守竞业限制吗？` | 命中第23条、第24条 |

**可复制的单行版本**（任选其一，直接粘进输入框）：

```
公司违法辞退我，月薪12000、工作3年7个月，能赔多少？
```

## 3. 实际会看到什么（真实跑出来的输出）

### 问题 1：违法辞退赔偿

> 输入：`公司违法辞退我，月薪12000、工作3年7个月，能赔多少？`

回答（Mock 模式，约 3.7 秒）：

```
[MOCK] 以下是基于检索到的法条原文的抽取式回答（未调用真实大模型）：
1. 《劳动合同法》第八十七条规定：用人单位违反本法规定解除或者终止劳动合同的，
   应当依照本法第四十七条规定的经济补偿标准的二倍向劳动者支付赔偿金。
2. 《劳动法》第二十八条规定：用人单位依据本法第二十四条、第二十六条、第二十七条
   的规定解除劳动合同的，应当依照国家有关规定给予经济补偿。
……
以上为法条原文要点，具体适用需结合完整事实与当地裁判口径；本回答不构成正式法律意见。
```

下方还会显示：
- **引用法条**：`《劳动合同法》第八十七条`、……
- **🔍 检索轨迹**表格：每条候选法条的 dense 分、BM25 分、RRF 分、rerank 分、来源通道（dense/bm25/both）、是否被零样本过滤保留（✅/❌）
- **⏱ 耗时**：plan / retrieve / rerank / filter / generate 各阶段毫秒数

### 问题 2：多意图（未签合同 + 被辞退）

> 输入：`入职8个月没签劳动合同，被辞退能同时要双倍工资和赔偿金吗？`

会先看到「**多意图分解**（2 个子查询）」，然后回答同时引用：
- 《劳动合同法》**第八十七条**（违法解除赔偿金）
- 《劳动合同法》**第八十二条**（未签书面合同二倍工资）

### 问题 3：社保补缴

> 输入：`公司一直不给我缴社保，我可以要求补缴吗？`

引用：
- 《社会保险法》**第六十三条**（责令限期缴纳或补足）
- 《社会保险法》**第八十六条**（滞纳金 + 罚款）

## 4. 两种模式：Mock vs 真实大模型

| | 离线 Mock（当前默认） | 真实大模型 |
|---|---|---|
| 需要 API Key | 不需要 | 需要 `OPENAI_API_KEY` |
| 回答方式 | **抽取式拼接法条原文**（明确标注 `[MOCK]`） | 真正的 LLM 生成 + 法律推理 |
| 零样本过滤 | 启发式规则（近似判断） | 真正的 LLM 判断"是否适用" |
| 用途 | 演示链路、面试现场、无网环境 | 真实问答效果 |
| 如何开启 | 默认 | 设环境变量后重启：见下 |

开启真实模型（任何 OpenAI 兼容端点：OpenAI / DeepSeek / 通义 / vLLM 均可）：

```powershell
cd "D:\Vibe Coding Projects\01-labor-law-rag"
$env:OPENAI_API_KEY  = "sk-你的key"
$env:OPENAI_BASE_URL = "https://api.openai.com/v1"   # 可选
$env:OPENAI_MODEL    = "gpt-4o-mini"                  # 可选
$env:HF_HUB_DISABLE_XET = "1"
& "D:\Vibe Coding Projects\.venv-rag\Scripts\chainlit.exe" run app\chainlit_app.py --host 127.0.0.1 --port 8000
```

> 注意：当前 Chainlit app 默认 `RAGService.load_or_build()` 不强制真实模型。
> 若要让 UI 用真实 LLM，把 `app/chainlit_app.py` 里 `svc = RAGService.load_or_build()` 改成
> `svc = RAGService.load_or_build(prefer_real_llm=True)` 后重启即可（一行改动）。

## 6. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 页面打不开 / 连接被拒绝 | Chainlit 服务没启动或已退出 | 按第 1 节命令重新启动 |
| 第一次发消息要等 5~10 秒 | 首次加载 BGE + reranker 模型 | 正常现象，之后每条 2~4 秒 |
| 回答以 `[MOCK]` 开头 | 当前离线 Mock 模式 | 属预期；配置 API Key 并用真实模式 |
| UI 里回答没有"法律推理" | Mock 是抽取式拼接 | 同上，真实模型才有推理能力 |
| 中文显示乱码 | 终端编码问题（仅 CLI） | 设置 `$env:PYTHONIOENCODING="utf-8"` |
| 想换端口 | 8000 被占用 | 加 `--port 8001` |

## 7. 演示范例流程（面试现场 3 分钟版）

1. 打开 http://127.0.0.1:8000 ，说明"知识库是 4 部法律 357 条真实法条"；
2. 输入问题 1 → 指出回答里的 **第87条引用** 和下方 **检索轨迹表**（dense/BM25/RRF/rerank 四列分数）；
3. 输入问题 2 → 指出 **多意图分解** 把一句话拆成"没签合同"和"违法辞退"两个子查询；
4. 打开 `01-labor-law-rag/data/eval/report.md` → 讲 50 题消融（哪一层涨了多少、哪一层反而降了）；
5. 收尾：强调离线 Mock 也能完整复现，真实模型只需一个环境变量。

## 5. 本次验收发现并修复的 bug

**问题**：视觉数据集的 `data/data.yaml` 在生成时写死了**绝对路径**。项目文件夹改名/移动后，YOLO 报：

```
FileNotFoundError: Dataset '.../data/data.yaml' images not found,
missing path 'D:\Vibe Coding Projects\03-vision-ocr-demo\data\images\val'
```

**修复**（已提交）：

1. `scripts/make_dataset.py`：生成 `path: .`（相对路径，不再写死本机路径）；
2. `src/yolo_detect.py`：新增 `normalize_data_yaml()`，每次运行前把 yaml 复制为 `.data_runtime.yaml` 并写入当前数据目录绝对路径，再交给 ultralytics（不改动被跟踪文件）；
3. `.gitignore` 忽略 `.data_runtime.yaml`。

**验证**：修复后 YOLO 评估/推理、OCR 全部通过（见 §4 #4~#6）。
